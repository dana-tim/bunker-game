# БУНКЕР — онлайн-гра для друзів

Локальна браузерна гра «Бункер»: хост створює кімнату, друзі приєднуються за кодом,
кожному роздаються приховані картки (Професія, Здоров'я, Вік/стать, Хобі, Фобія,
Багаж, Факт), гравці по черзі розкривають картки, а після кожного раунду голосують,
хто вибуває з бункера. Гра закінчується, коли живих гравців стає рівно стільки,
скільки місць у бункері.

## Структура проєкту

```
bunker-game/
├── server.js          # Backend: Express + Socket.io, вся ігрова логіка
├── cards.json          # Дані карток — сюди вставляєте свої варіанти
├── package.json
└── public/
    └── index.html       # Весь frontend (HTML+CSS+JS, SPA) в одному файлі
```

Все загальнодоступний стан гри тримається в пам'яті сервера (без бази даних) —
цього достатньо для гри на один вечір. Якщо сервер перезапустити, кімнати зникнуть.

## 1. Встановлення (VS Code або PyCharm)

Вам знадобиться **Node.js 18+** ([nodejs.org](https://nodejs.org)).

1. Розпакуйте/скопіюйте папку `bunker-game` на комп'ютер.
2. Відкрийте папку у VS Code (`File → Open Folder`) чи PyCharm
   (`File → Open`, PyCharm також чудово підтримує Node.js-проєкти).
3. Відкрийте вбудований термінал (`` Ctrl+` `` у VS Code, або `View → Tool Windows → Terminal` у PyCharm)
   і виконайте:

   ```bash
   cd bunker-game
   npm install
   ```

   Це встановить `express` та `socket.io`.

4. Запустіть сервер:

   ```bash
   npm start
   ```

   Побачите в консолі:

   ```
   Бункер запущено: http://localhost:3000
   ```

5. Відкрийте у браузері `http://localhost:3000` — маєте побачити головний екран гри.

### Налаштування карток під себе

Відкрийте `cards.json`. Структура:

```jsonc
{
  "disasters": ["текст катастрофи 1", "текст катастрофи 2", ...],
  "bunkers": [
    { "description": "...", "supplies": "...", "size": "..." }
  ],
  "categories": {
    "profession": { "label": "Професія", "items": ["Лікар", "Інженер", ...] },
    "health":     { "label": "Здоров'я",  "items": [...] },
    "ageGender":  { "label": "Вік та Біологічна стать", "items": [...] },
    "hobby":      { "label": "Хобі", "items": [...] },
    "phobia":     { "label": "Фобія / Особливість", "items": [...] },
    "baggage":    { "label": "Багаж / Інвентар", "items": [...] },
    "fact":       { "label": "Додатковий факт", "items": [...] }
  }
}
```

Просто редагуйте масиви `items` (додавайте/видаляйте рядки) та `disasters`/`bunkers` —
ключі категорій (`profession`, `health` тощо) міняти не треба, вони прив'язані до коду.
Кожному гравцю під час старту гри випадково видається по одній картці з кожної категорії
(можливі повтори між різними гравцями — це нормально для «Бункера»).
Перезапустіть сервер (`Ctrl+C`, потім знову `npm start`), щоб зміни підхопились.

## 2. Як грати локально в одній Wi-Fi мережі

Якщо всі друзі підключені до одного Wi-Fi (наприклад, вдома), можна обійтись без ngrok:

1. Дізнайтесь свою локальну IP-адресу:
   - Windows: `ipconfig` (шукайте `IPv4 Address`, напр. `192.168.0.15`)
   - macOS/Linux: `ifconfig` або `ip addr` (шукайте адресу в мережі `192.168.x.x`)
2. Запустіть сервер (`npm start`).
3. Друзі відкривають у браузері `http://ВАША_IP:3000`, наприклад `http://192.168.0.15:3000`.

Якщо не з'єднується — перевірте, чи фаєрвол не блокує порт 3000.

## 3. Як розшарити гру через інтернет (ngrok)

Якщо друзі не в одній мережі (грають з різних міст), використайте **ngrok** —
він створює тимчасове публічне посилання на ваш локальний сервер.

### Встановлення ngrok

1. Зареєструйтесь безкоштовно на [ngrok.com](https://ngrok.com/) та скачайте клієнт
   для вашої ОС, або встановіть через пакетний менеджер:
   - macOS (Homebrew): `brew install ngrok`
   - Windows (Chocolatey): `choco install ngrok`
   - Або просто скачайте бінарник з сайту й розпакуйте.
2. Авторизуйте ngrok своїм токеном (він показаний у вашому кабінеті на ngrok.com):

   ```bash
   ngrok config add-authtoken ВАШ_ТОКЕН
   ```

### Запуск

1. В одному терміналі запустіть гру:

   ```bash
   npm start
   ```

2. У **другому** терміналі (не закриваючи перший) запустіть тунель на той самий порт:

   ```bash
   ngrok http 3000
   ```

3. ngrok виведе щось на кшталт:

   ```
   Forwarding    https://a1b2-12-34-56-78.ngrok-free.app -> http://localhost:3000
   ```

4. Скопіюйте посилання `https://....ngrok-free.app` і надішліть друзям у месенджер.
   Вони відкривають це посилання у браузері (працює й на телефонах) і бачать той
   самий головний екран гри.

5. Ви як хост відкриваєте `http://localhost:3000` (або те саме ngrok-посилання) у себе,
   створюєте кімнату, копіюєте код кімнати (кнопка «Скопіювати посилання» у лобі вже
   формує повне посилання виду `https://....ngrok-free.app/?code=XXXXX`) і надсилаєте його
   гравцям — код підставиться автоматично.

> Безкоштовний ngrok-тунель живе, поки відкритий термінал з `ngrok http 3000`, і
> посилання змінюється щоразу під час нового запуску. Не закривайте термінали з
> `npm start` та `ngrok http 3000`, поки триває гра.

## 4. Хід гри (коротко для гравців)

1. **Лобі** — хост задає кількість місць у бункері (скільки виживе), гравці приєднуються
   за кодом/посиланням, хост тисне «Почати гру».
2. **Розкриття карток** — гравці по черзі обирають одну зі своїх прихованих карток
   і розкривають її для всіх. Решта карток видно тільки їм самим.
3. **Голосування** — коли всі живі гравці розкрили по картці цього раунду, автоматично
   починається анонімне голосування: кожен обирає, хто, на його думку, не повинен
   потрапити до бункера.
4. **Вибування** — гравець з найбільшою кількістю голосів вибуває, і всі його приховані
   картки розкриваються повністю. Хост тисне «Наступний раунд».
5. Гра завершується, коли кількість живих гравців дорівнює заданій кількості місць
   у бункері — вони і є переможцями-виживальниками.

Хост завжди має додаткові кнопки-«запобіжники»: примусово почати голосування (якщо
хтось довго думає) і примусово завершити голосування (якщо хтось не встиг проголосувати
чи вийшов з гри).

Приємної гри! 🛡️
