# Як зробити «Бункер» доступним для всіх: публічне посилання + код кімнати

Мета: ви один раз викладаєте гру в інтернет, отримуєте **постійне посилання**
(наприклад `https://bunker-game.onrender.com`), і будь-хто з будь-якої мережі
та пристрою заходить у гру. Далі працює так, як ви хотіли:

- хост створює кімнату й отримує **5-символьний код** (наприклад `K7M2P`);
- друзі відкривають посилання, вводять нікнейм і код **або** відкривають
  готове запрошення `https://…/?code=K7M2P` (код підставиться сам);
- кімнат може бути багато одночасно — кожна має свій код і не бачить інших.

Ngrok при цьому **не потрібен**. Ваш комп'ютер теж може бути вимкнений.

---

## Відповідь на питання про термінал

Коли в інструкції сказано «виконайте в терміналі» — це **термінал на вашому
комп'ютері**. Найзручніше — вбудований у VS Code (`Terminal → New Terminal`),
але підійде й звичайний PowerShell. Термінал має бути відкритий **у папці
проєкту** (в запрошенні видно `PS D:\bunker-game>`). Для публічного
хостингу з цього файлу термінал потрібен лише для кількох команд `git`.

---

## Крок 1. Перевірте, що гра працює локально

```powershell
npm install
npm start
```

Відкрийте `http://localhost:3000`. Якщо бачите екран гри — йдемо далі.
Зупиніть сервер (`Ctrl+C`).

## Крок 2. Завантажте проєкт на GitHub

Render бере код з GitHub, тому потрібен безкоштовний акаунт на github.com.

**Спосіб А — без командного рядка (найпростіше):**

1. На github.com натисніть **New repository**, назва `bunker-game`,
   тип **Public** або **Private**, натисніть **Create repository**.
2. На сторінці нового репозиторію натисніть **uploading an existing file**.
3. Перетягніть у вікно **вміст папки** `bunker-game`: `server.js`,
   `cards.json`, `package.json`, `render.yaml`, `.gitignore` і папку `public`.
   **Не** завантажуйте `node_modules`.
4. Натисніть **Commit changes**.

**Спосіб Б — через git у терміналі VS Code** (у папці проєкту):

```powershell
git init
git add .
git commit -m "Bunker game"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/bunker-game.git
git push -u origin main
```

## Крок 3. Створіть сервіс на Render

1. Зареєструйтесь на [render.com](https://render.com) (можна через GitHub).
2. Натисніть **New + → Web Service**.
3. Підключіть GitHub і виберіть репозиторій `bunker-game`.
4. Заповніть поля:
   - **Language / Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. Натисніть **Create Web Service** і зачекайте 1–3 хвилини, поки в логах
   з'явиться `Бункер запущено`.
6. Вгорі сторінки сервісу з'явиться ваше публічне посилання вигляду
   `https://bunker-game-xxxx.onrender.com`. Це і є адреса гри.

> Якщо в репозиторії є `render.yaml` (він уже в проєкті), Render також
> може створити сервіс автоматично: **New + → Blueprint** і виберіть репозиторій.

## Крок 4. Грайте з друзями

1. Відкрийте своє `…onrender.com` посилання, введіть нікнейм, вкажіть
   кількість місць у бункері та натисніть **«Створити кімнату»**.
2. У лобі натисніть **«Скопіювати посилання»** і надішліть його друзям
   у Telegram/Viber/WhatsApp. Або просто назвіть їм код кімнати.
3. Друзі відкривають посилання з будь-якого пристрою, вводять нікнейм і
   натискають **«Приєднатись»** (код уже підставлено).
4. Коли всі в лобі — хост натискає **«Почати гру»**.

## Важливі особливості безкоштовного хостингу

За документацією Render, безкоштовні сервіси «засинають» після 15 хвилин
без активності й прокидаються при наступному запиті або новому
WebSocket-з'єднанні. Звідси практичні поради:

- **Відкрийте посилання за 1–2 хвилини до початку гри.** Перший вхід після
  простою може тривати до хвилини, поки сервер прокинеться.
- Під час гри активність тримає сервер активним (з лютого 2026 Render
  враховує WebSocket-повідомлення як активність).
- **Стан кімнат зберігається в пам'яті.** Якщо сервер перезапуститься або
  ви завантажите нову версію коду, активні кімнати зникнуть. Не оновлюйте
  код у розпал гри.
- Умови безкоштовного тарифу можуть змінитись, тож перегляньте їх на
  render.com перед тим, як будете покладатись на сервіс.

## Що робити, якщо гравець втратив зв'язок

Ця версія гри вже це враховує:

- Телефон заснув, вкладку перезавантажили або зник інтернет — гравець
  автоматично повертається в **ту саму кімнату** зі своїми картками, щойно
  сторінка знову з'єднається з сервером.
- Для інших він відображається з позначкою «⚠ немає зв'язку».
- Якщо гравець не повернувся **2 хвилини**, його прибирають з кімнати,
  а якщо це був хост — права хоста переходять до іншого гравця.
- Якщо хтось завис під час свого ходу чи голосування, хост може
  скористатись кнопками «Примусово почати голосування» та
  «Примусово завершити голосування».

## Альтернативи Render

Гра — звичайний Node.js-сервер із WebSocket, тому її можна розмістити також
на Railway, Fly.io або на власному VPS (команда запуску там та сама:
`npm install` і `npm start`, порт береться зі змінної `PORT`).
Для швидкого тесту «на пів години» можна й надалі користуватись ngrok.
